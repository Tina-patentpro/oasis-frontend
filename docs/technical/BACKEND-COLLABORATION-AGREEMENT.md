- **CMS**（内容管理系统）- 管理用户界面交互和内容组织

## 详细功能说明

### 1. 顶部导航栏

- **绿洲慧写·工作区**（CMS）
- **< 侧边栏开关** - 显示/隐藏左侧边栏
- **🔔 通知中心** - 查看系统通知和提醒（CMS+DB）
  - 全部/未读：选择查看全部通知或仅查看未读通知（DB）
  - 全部标记为已读：将所有未读通知标记为已读（DB）
  - 清空所有：删除所有通知，不能恢复（DB）

- **👤 用户菜单**
  - **设置**：
    - **个人信息**：用户可以定制头像，更改用户名，邮箱和手机号。这些信息主要用于内容生成（如果需要）和服务（DB）
      - **推荐奖励**：
        - **使用推荐码**：输入好友分享的推荐码，双方各获得奖励（奖励金额由CMS配置，默认50元）（DB）
        - **我的推荐码**：生成专属推荐码分享给好友，每成功推荐一位好友即可获得奖励（DB）
          - 推荐码展示：显示您的专属推荐码（格式：字母+数字组合）（DB）
          - 一键复制：快速复制推荐码到剪贴板
          - 使用统计：已使用次数/最大使用次数（由CMS配置，默认10次）（DB）
          - 收益统计：单次奖励金额和累计收益（DB）
          - 推荐记录：最近5条推荐记录，包含时间、类型（推荐成功/使用推荐码）、奖励金额（DB）
        - **推荐规则**：
          - 每个推荐码有使用次数限制（由系统配置）
          - 每位新用户只能使用一次推荐码
          - 推荐奖励金额由系统配置决定
          - 奖励将自动发放到您的账户余额
    - **充值/余额**：查看个人账户当前余额。支持两种充值方式（DB+CMS）：
      - **定额充值**：提供多个预设充值套餐，套餐种类、金额和赠送金额由CMS配置，选择后由数据库自动执行充值和赠送（CMS+DB）
        - 示例套餐：50元基础套餐、100元推荐套餐（赠送10元）、200元超值套餐（赠送30元）
      - **自定义金额**：用户可输入任意金额充值，最低1元，支持小数点后两位（DB）
      - 我们建议仅充值近期会使用的额度。开发票需求请联系客服
    - **使用记录**：查看或导出账户交易明细（DB），包括：
      - 消费：使用AI功能产生的费用扣除（DB）
      - 充值：用户主动充值的金额增加（DB）
      - 赠送：系统或活动赠送的余额（包括推荐奖励）（DB）
      - 返还：因任务失败等原因的退款（DB）
      - 注：推荐码奖励会显示为"赠送 - 推荐奖励"，方便用户追踪推荐收益
    - **数据管理**：导出或删除所有数据，包含会话，文件，数据库记录（DB+FS）。清理浏览器缓存数据以解决缓存造成的运行问题。

  - **帮助文档**：快速学习怎样使用绿洲慧写人工智能专利辅助撰写工具（CMS）
  - **联系客服**：客服微信二维码（CMS）
  - **项目管理中心**（DB）：
    - 按时间或客户分类的使用统计数据，完成会话数量，生成文档数量，检索专利数量，累计使用时间（DB）
    - 工作量趋势，基于工作量设置和使用统计数据计算并以柱形图形式体现（DB）
    - 每个客户的工作量（DB）
    - 每种任务类型的工作量（DB）
    - 重要活动时间轴（DB）
    - To Do清单（来自于已完成会话的下一步建议）（DB）
  - **项目详情页面**：
    - **编辑项目**：支持动态字段编辑，可修改客户信息和基础信息（CMS+DB）
    - **导出项目**：
      - 快速导出：通过对话框选择要导出的数据类型（运行记录、生成文件、主要数据、专利检索、项目信息）（DB+FS）
      - 精确导出：进入选择模式，在界面中直接勾选具体数据项，支持跨tab多选（DB+FS）
    - **项目数据展示**（按Tab分类）：
      - 运行记录：显示工具+模型名称、生成时间、版本号，支持预览和下载（DB）
      - 生成文件：显示文件名称、工具+模型名称、版本号、生成时间+文件大小，支持预览和下载（DB+FS）
      - 主要数据：显示参数名称、工具+模型名称、版本号、生成时间+文件大小，支持预览和下载（DB）
      - 专利检索：显示专利标题、摘要片段、授权时间+文件大小，支持预览和下载（DB+FS）
  - **主题**：切换视觉主题（清新绿/科技蓝/活力橙/永恒灰）
  - **登出**：退出当前的登录

- **💬 对话开关** - 显示/隐藏右侧对话面板

### 2. 左侧边栏

- **模型分类标签**
  - **技术研发**：供发明人或专利代理师进行研发初期的快速调研，创新点挖掘和发明方向选择
  - **专利撰写**：辅助发明人或专利代理师进行技术交底书完善，权利要求书和说明书撰写，专利稳定性快速评估，审查意见回复
  - **辅助工具**：帮助发明人进行术语校验，申请文件添加编号，合规性（含26.3/26.4）快速评估，附图说明生成

- **模型选择**
  - 根据工作任务选择需要的模型（模型列表由CMS配置）
  - 选择适合的版本（版本列表由CMS配置，执行由Dify）
    - **Fast版**：快速生成模式，供草稿生成任务使用。使用成本约为Basic版的50%，使用时间约为Basic版的1/3-2/3
    - **Basic版**：标准模式，供基本任务使用。标准生成能力，满足常规撰写流程
    - **Pro版**：深度思考模式，供高价值专利生成任务使用。通过读取更多数据，思考更长时间，以提供高质量输出。使用成本约为Basic版的3-5倍
  - **模型说明**：为每一种模型提供说明（CMS）

- **独立会话历史**（DB）
  - **重命名**：独立会话默认以生成模型+时间命名。用户可以修改命名以方便后续使用和管理（DB）
  - **关联项目**：将独立会话关联到已经建立的项目。如果还没有已经建立的项目，可以创建新的项目（DB）
  - **导出**：将会话以 zip 文件形式导出，其中文本和数据以 md 格式保存（DB+FS）
  - **删除**：删除本会话的历史记录。删除之后将无法恢复（DB）

- **项目管理**（DB）
  - 快速寻找项目及包含的关联会话（DB）
  - 进入项目详情页面，包含以下功能：

  **上部区域 - 项目概况**
  - 项目状态标签：显示项目当前阶段
  - 项目名称和编号：PRJ-2025-XXXX格式
  - 操作按钮：
    - **编辑项目**：支持动态字段编辑，可修改客户信息和基础信息（CMS+DB）
      - 客户信息：客户名称、联系人、联系方式、合作类型等
      - 基础信息：立项时间、最近更新、截止日期、交付物等
      - 支持6种字段类型：文本、多行文本、数字、日期、日期时间、下拉选择
    - **导出**：快速导出项目数据（DB+FS）
    - **删除项目**：删除整个项目及相关数据
  - 信息卡片：
    - 客户信息卡片：显示客户相关信息
    - 基础信息卡片：显示项目基础信息

  **下部区域 - 项目数据Tab**（按Tab分类展示）
  - **运行记录**：显示项目的所有工作流执行记录（DB）
    - 显示内容：工具+模型名称、生成时间、版本号
    - 操作按钮：预览、下载
  - **生成文件**：显示项目生成的所有文件（DB+FS）
    - 显示内容：文件名称、工具+模型名称、版本号、生成时间+文件大小
    - 操作按钮：预览、下载
  - **主要数据**：显示项目的主要数据文件（DB）
    - 显示内容：参数名称、工具+模型名称、版本号、生成时间+文件大小
    - 操作按钮：预览、下载
  - **专利检索**：显示项目的专利检索结果（DB+FS）
    - 显示内容：专利标题、摘要片段、授权时间+文件大小
    - 操作按钮：预览、下载

  **导出功能**（两种模式）
  - **快速导出**：点击"导出"按钮
    - 打开选择对话框，选择要导出的数据类型
    - 可选：运行记录、生成文件、主要数据、专利检索、项目信息
    - 支持全选/全不选
    - 显示预计文件大小
    - 打包为zip文件下载（DB+FS）
  - **精确导出**：点击"选择导出"按钮
    - 进入选择模式，在数据界面中直接勾选具体数据项
    - 支持跨tab多选
    - 实时显示已选数量
    - 选中项高亮显示
    - 点击"确认导出"打包为zip文件下载（DB+FS）

### 3. 中间工作区

- **进度指示** - 显示当前工作流程步骤和实时进度（CMS）
  - 工作流步骤由CMS配置，不同工具可以有不同的步骤数量和名称
  - 默认步骤：输入材料 → 生成内容 → 校验与下载
  - 示例自定义步骤：
    - 权利要求生成：输入方案 → 生成权利要求 → 优化与导出
    - 说明书生成：准备材料 → 生成说明书 → 审核与下载
  - 实时进度由Dify通过http节点向前端传输里程碑完成情况（Dify）

- **输入区** - 分章节输入材料，支持文件和图片上传。分章和是否支持文件或图片上传根据不同模型独立设定。（CMS+Dify）
  - **+**：向模型会话添加本地文件/图片

- **输出区** - 展示生成内容，支持富文本/源码模式，可以兼容markdown标题，正文和列表，html，表格，图片，代码，公式和mermaid图型。（Dify）

- **指令栏**
  - **关联项目**：选择会话属于哪个项目。此选项直接影响会话归属和可读取的历史数据，包括输入数据和生成数据（DB）
  - **+**（新建项目）：如果会话属于一个尚未设置的项目，可以使用此按钮调取快速创建新项目页面
  - **自动/对比/上下**：设定输入区和输出区的布局
    - 自动：自动根据可用屏幕区域宽度选择上下布局和左右布局
    - 对比：强制选择左右布局，且自动关闭左栏和右栏以获得最大可用屏幕宽度
    - 上下：强制选择上下布局
  - **读取**：可以读取本项目内历史会话中的涉及数据和文件（包括输入数据和生成数据）。涉及哪些数据和文件根据不同模型独立设定。此功能从数据库/文件系统调取历史数据，省去用户手动查找和复制粘贴的时间。（CMS+DB+FS）
  - **复制文本**：复制当前章节的内容
  - **清空**：清空所有章节的输入内容。清空后可使用 Ctrl+Z 快捷键恢复（最多可恢复最近10次操作，撤销历史保存在会话内存中，刷新页面后会丢失）
  - **一键添加示例**：根据不同的模型，填入预设的输入和输出示例，供用户参考（CMS）
  - **富文本/源码**：用户可以在默认的富文本显示之外，使用源码显示以拷贝代码，公式和Mermaid图型的源码，图片的链接等资源
  - **生成**：点击启动模型执行生成任务，完成后按定价扣除费用（Dify执行，CMS配置价格，DB记录消费）
  - **下载**：点击打开生成文件下载多选页面。可以选择需要的文件进行下载（Dify生成，FS存储）
  - **下一步➡**：自动切换到下一个工作流程并将当前生成内容转入下一模型（CMS配置工作流链）

### 4. 右侧对话面板

- **对话模式**
  - **通用对话**：直接调用通用模型能力进行对话，适合非专利生成任务（Dify执行，CMS配置价格，DB记录消费）
  - **语义生图**：通过对话实现基于语义的需求理解和文生图。生成的图片可直接作为技术文献插图使用，也可修改后用于专利附图（Dify执行，CMS配置价格，DB记录消费）
  - **工作聚焦**：以对话形式调用所有绿洲模型的能力，通过人工干预精调实现质量提升。特别适合权利要求书、审查意见答复的辅助撰写任务（Dify执行，CMS配置价格，DB记录消费）

- **消息输入框**：与AI助手对话
  - **+**：向模型会话添加本地文件/图片

- **指令栏**
  - **独**：状态指示，提示用户现有对话是否与项目关联。
    - 通用对话模式：自动高亮且不可关闭（独立会话）
    - 语义生图/工作聚焦模式：默认不亮，可点击切换为高亮（独立会话）
    - 当'独'高亮时，不能调取模型能力，不能读取项目文档也无法将对话保存为项目会话
  - **读取**：读取项目历史内容，包括输入材料和生成结果，用于会话上下文。此功能从数据库/文件系统调取历史数据。（CMS限定读取范围+DB+FS）
  - **清空对话**：清空并开始新的会话
  - **发送**：将输入框内的指令发送到对话，启动模型执行生成任务，完成后按定价扣除费用（Dify执行，CMS配置价格，DB记录消费）

## 数据流说明

### 配置数据流 (CMS)

```
CMS → 前端
- 模型分类和工具列表
- 版本配置
- 工作流步骤
- 价格配置
- 充值套餐
- 帮助文档
```

### 用户数据流 (DB)

```
前端 ⇄ DB
- 用户信息
- 会话记录
- 项目数据
- 充值/消费记录
- 推荐关系
- 使用记录
```

### 文件数据流 (FS)

```
前端 → FS: 文件上传
FS → 前端: 文件下载
DB → FS: 文件关联信息
```

### AI 生成流 (Dify)

```
前端 → Dify: 生成请求
Dify → 前端: 流式/完整响应
Dify → FS: 生成文件存储
Dify → DB: 生成记录保存
```
