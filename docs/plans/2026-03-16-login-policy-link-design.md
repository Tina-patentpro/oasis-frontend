# 登录页政策提示设计

**目标**

在登录页增加一句明确提示：“请先阅读并同意隐私与服务政策”，并让“隐私与服务政策”可点击跳转到指定页面。

**已确认方案**

- 采用方案 A。
- 不新增勾选框。
- 不拦截登录流程。
- 仅在登录表单中增加提示文案和外部链接。

**设计说明**

- 提示放在“登录账号”按钮上方，属于用户提交前最容易注意到的位置。
- 文案保持简洁，避免引入新的操作负担。
- 链接使用新标签页打开，减少用户离开当前登录页后丢失输入的风险。
- 改动范围控制在登录表单和对应最小测试内，不调整注册页和整页布局。

**验收标准**

- 登录页出现“请先阅读并同意隐私与服务政策”。
- “隐私与服务政策”链接地址为 `https://www.oasisintwrite.com/privacy`。
- 链接可在新标签页打开。
- 原有登录流程和页面排版不受明显影响。
