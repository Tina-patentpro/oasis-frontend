# ai.service.ts 超长文件拆分计划

## 背景

`src/api/services/ai.service.ts` 当前有效行数约 711 行，是最后一个仍在 ESLint 超长文件豁免名单里的文件。该文件覆盖生成、聊天、上传、工作流列表和异步进度查询，风险高于普通服务文件。

## 计划

1. 先跑 AI 服务相关测试  
   - 做什么：执行 `createWithApi`、文本回退、进度查询、聊天、上传、工作流列表相关测试。
   - 为什么做：先确认拆分前行为稳定，后续验证拆分没有改变行为。
   - 完成标准：6 个专项测试文件全部通过。

2. 抽出纯辅助逻辑  
   - 做什么：把响应整理、文件输入整理、工作流列表整理、进度状态整理等不直接发请求的逻辑移到新文件。
   - 为什么做：这些逻辑不依赖 `AIService` 类内部状态，适合单独维护。
   - 完成标准：`ai.service.ts` 主要保留接口调用和业务入口。

3. 移除超长豁免并验证  
   - 做什么：从 `eslint.config.js` 的历史超长文件名单中移除 `ai.service.ts`。
   - 为什么做：让后续检查持续防止该文件再次变长。
   - 完成标准：`ai.service.ts` 有效行数小于 500，专项测试、类型检查和 lint 全部通过。

## 不做事项

- 不改 API 地址和参数。
- 不改重试、超时和上传行为。
- 不改聊天、生成、进度查询的返回结构。
- 不补做新的业务功能。
