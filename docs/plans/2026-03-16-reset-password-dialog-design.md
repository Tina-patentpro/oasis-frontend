# 忘记密码重置弹窗设计

**目标**

把登录页“忘记密码”当前的浏览器原生提示框，替换成一个更聚焦的“重置密码”弹窗，并在弹窗里展示客服二维码，引导用户扫码联系客服重置密码。

**已确认方案**

- 采用方案 A。
- 新增独立的“重置密码”弹窗。
- 弹窗内部复用现有微信客服二维码区域，不重新制作二维码资源。
- 提示用户扫码添加客服，并备注“重置密码”。

**设计说明**

- 弹窗只在密码登录模式下点击“忘记密码”时打开。
- 弹窗标题使用“重置密码”，正文聚焦在密码重置，不再沿用“联系客服”的泛化文案。
- 二维码区域直接复用现有 `WeChatSupportPanel`，保持图片、工作时间和视觉风格一致。
- 登录页容器负责管理弹窗开关状态，登录表单继续只负责抛出点击事件。

**验收标准**

- 点击密码登录页的“忘记密码”后，打开“重置密码”弹窗。
- 弹窗内出现“请扫码添加客服微信，并备注‘重置密码’”类提示。
- 弹窗内显示现有客服二维码。
- 短信登录页仍然不显示“忘记密码”。
