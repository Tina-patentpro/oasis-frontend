# session-click.ts 超长文件拆分计划

## 目标

把 `src/modules/workspace/hooks/sidebar/session-click.ts` 从单个超长文件拆成“主流程 + 小工具模块”，移除 `eslint.config.js` 里的超长豁免。

## 范围

- 只移动已有逻辑，不重写会话恢复业务。
- 优先拆出纯工具函数：调试日志、工具名匹配、输入恢复、聊天会话还原。
- 保留 `handleWorkspaceSessionClick` 的对外调用方式。

## 步骤

1. 跑现有会话点击测试  
   - 为什么：确认拆分前行为可作为基线。  
   - 完成标准：相关测试全部通过。

2. 拆出可独立复用的小工具模块  
   - 为什么：降低主文件行数，减少后续维护成本。  
   - 完成标准：主文件只保留主流程和必要编排。

3. 保持原导出与测试入口不变  
   - 为什么：避免影响其他模块引用。  
   - 完成标准：现有 import 不需要批量改造。

4. 移除超长豁免并验证  
   - 为什么：让代码检查重新覆盖该文件。  
   - 完成标准：目标文件低于 500 有效行，`type-check`、`lint`、相关测试通过。

## 风险控制

- 不改接口请求、状态写入、通知文案。
- 不改聊天/工作流会话恢复的数据结构。
- 若拆分后测试暴露时序问题，优先修复拆分造成的问题，不扩大重构范围。
