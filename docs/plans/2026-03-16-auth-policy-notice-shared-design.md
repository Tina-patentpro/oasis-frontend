# 认证页政策提示共用组件设计

**目标**

把登录页和注册页底部的政策提示抽成一个共用小组件，并把文案统一成更常见的表达方式。

**已确认方案**

- 抽取一个认证页共用政策提示组件。
- 登录页显示“登录即表示你已阅读并同意隐私与服务政策”。
- 注册页显示“注册即表示你已阅读并同意隐私与服务政策”。
- 链接继续指向 `https://www.oasisintwrite.com/privacy`，并在新标签页打开。

**设计说明**

- 共用组件接收一个简单的动作文案参数，例如“登录”或“注册”。
- 组件内部统一维护文案样式、链接地址和安全属性，避免两处重复代码。
- 登录页与注册页只保留业务表单逻辑，不再各自维护政策提示的 HTML 结构。
- 现有测试继续覆盖登录页和注册页渲染结果，确认共用组件接入后对外表现不变，只更新文案。

**验收标准**

- 登录页和注册页都通过同一个组件显示政策提示。
- 登录页文案为“登录即表示你已阅读并同意隐私与服务政策”。
- 注册页文案为“注册即表示你已阅读并同意隐私与服务政策”。
- 链接地址正确，新标签页打开。
