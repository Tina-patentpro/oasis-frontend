# 注册页政策提示设计

**目标**

把注册页底部原来的“我已阅读并同意服务条款”勾选区，改成与登录页一致的静态提示文案和外部链接。

**已确认方案**

- 采用方案 A。
- 删除勾选框。
- 删除“必须勾选才能注册”的前端限制。
- 在“注册账号”按钮上方增加与登录页一致的提示文案和链接。
- 为兼容后端，注册提交时默认携带 `acceptTerms: true`。

**设计说明**

- 改动只发生在注册表单组件内部，不调整认证页整体布局。
- 提示文案沿用登录页的视觉样式，保证登录与注册体验统一。
- 链接指向 `https://www.oasisintwrite.com/privacy`，用新标签页打开，避免影响用户继续填写表单。
- 去掉勾选框后，同时删除对应的报错提示和校验逻辑，避免界面与行为不一致。

**验收标准**

- 注册页不再显示勾选框。
- 注册页显示“请先阅读并同意隐私与服务政策”。
- “隐私与服务政策”链接地址正确，且新标签页打开。
- 注册提交不再依赖勾选框。
