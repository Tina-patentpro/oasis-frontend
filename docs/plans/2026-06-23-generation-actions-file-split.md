# generation-actions.ts 超长文件拆分计划

## 目标

把 `src/modules/workspace/hooks/content-sections/generation-actions.ts` 拆成更小的模块，并移除 `eslint.config.js` 里的超长豁免。

## 拆分范围

- 只移动已有逻辑，不改变生成、上传、轮询、下载、会话追踪行为。
- 优先拆出类型定义、上传处理、恢复状态监听、常用动作、下载/下一步等低耦合逻辑。
- 保留 `useGenerationActions` 的对外返回结构不变。

## 步骤

1. 跑现有 generation-actions 专项测试  
   - 为什么：确认拆分前行为稳定。  
   - 完成标准：3 个相关测试文件全部通过。

2. 抽出类型和纯工具函数  
   - 为什么：降低主文件长度，且行为风险最低。  
   - 完成标准：类型检查通过。

3. 抽出文件上传和局部动作 hook  
   - 为什么：上传逻辑独立、测试覆盖较好。  
   - 完成标准：专项测试继续通过。

4. 抽出生成结果恢复、下载、下一步等辅助逻辑  
   - 为什么：让主 hook 专注于生成请求主流程。  
   - 完成标准：主文件低于 500 有效行。

5. 移除豁免并验证  
   - 为什么：让代码检查重新覆盖该文件。  
   - 完成标准：`type-check`、`lint`、专项测试全部通过。

## 风险控制

- 不改 API 请求参数。
- 不改通知文案。
- 不改返回字段名。
- 每批拆分后至少跑类型检查，最终跑专项测试和完整 lint。
