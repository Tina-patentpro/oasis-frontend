# useWorkspaceSidebar.ts 超长文件拆分计划

## 目标

降低 `src/modules/workspace/hooks/useWorkspaceSidebar.ts` 的文件长度，移除超长豁免，同时不改变侧边栏项目、会话、刷新、筛选和点击行为。

## 拆分策略

1. 先跑现有专项测试  
   - 为什么：侧边栏包含项目列表、会话列表、刷新和点击恢复，先确认基线。  
   - 完成标准：`useWorkspaceSidebar.sprint.test.ts` 通过。

2. 抽出“会话刷新协调”逻辑  
   - 为什么：刷新、sprint 追踪和乐观会话提示是相对独立的一块。  
   - 完成标准：主文件不再直接承载该块细节。

3. 抽出“列表派生数据”逻辑  
   - 为什么：项目排序、可见会话、分页视图等是纯计算，适合独立 hook。  
   - 完成标准：主文件只接收已整理好的列表视图。

4. 移除豁免并验证  
   - 为什么：让代码检查重新覆盖该文件。  
   - 完成标准：目标文件低于 500 有效行，专项测试、类型检查、代码检查通过。

## 风险控制

- 不改 API 调用参数。
- 不改用户可见文案。
- 不改项目/会话操作入口。
- 每一步拆分后都运行现有测试或类型检查。
