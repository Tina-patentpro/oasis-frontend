# 推荐码功能说明

## 功能概述

在个人信息设置页面中新增推荐码功能，包括两个主要功能模块：

1. **使用推荐码**：用户输入收到的推荐码，获得奖励
2. **我的推荐码**：生成并分享自己的推荐码，推荐他人获得奖励

## 功能详情

### 1. 使用推荐码

**位置**：个人信息页面 > 推荐奖励 > 使用推荐码

**功能描述**：

- 用户可以输入好友分享的推荐码
- 输入框自动转换为大写字母
- 点击"使用"按钮提交推荐码
- 成功使用后，双方各获得奖励（奖励金额由CMS配置）
- 按钮状态：提交中 / 已使用 / 使用
- 每位用户只能使用一次推荐码

**交互流程**：

1. 用户在输入框中输入推荐码
2. 点击"使用"按钮
3. 系统验证推荐码有效性
4. 验证成功后，系统自动发放奖励到账户余额
5. 显示成功提示信息

### 2. 我的推荐码

**位置**：个人信息页面 > 推荐奖励 > 我的推荐码

**功能描述**：

- 首次进入时显示"生成我的推荐码"按钮
- 点击后生成专属推荐码（格式：REF + 6位随机字符）
- 推荐码信息展示：
  - 推荐码（大号字体显示）
  - 复制按钮（一键复制到剪贴板）
  - 已使用次数 / 最大使用次数
  - 单次奖励金额
  - 累计收益

**推荐记录**：

- 显示最近5条推荐记录
- 记录包含：时间、类型（推荐成功/使用推荐码）、奖励金额
- 使用表格形式展示，便于查看

## 技术实现

### 数据类型定义

```typescript
// 推荐码信息
interface ReferralCode {
  code: string // 推荐码
  usedCount: number // 已使用次数
  maxUses: number // 最大使用次数（CMS配置）
  rewardAmount: number // 单次奖励金额（CMS配置）
  totalEarned: number // 累计收益
  createdAt: string // 创建时间
}

// 推荐记录
interface ReferralRecord {
  id: string
  date: string
  type: 'used' | 'earned' // used: 使用推荐码, earned: 推荐成功
  code: string
  amount: number
}
```

### 核心函数

1. **handleSubmitReferralCode**：处理推荐码提交
   - 验证输入
   - 调用API验证推荐码
   - 发放奖励
   - 更新状态

2. **handleGenerateReferralCode**：生成推荐码
   - 生成随机推荐码
   - 调用API创建推荐码
   - 更新状态

3. **handleCopyReferralCode**：复制推荐码
   - 使用Clipboard API复制
   - 显示成功提示

## CMS配置项

需要在后台CMS系统中配置以下参数：

1. **推荐奖励金额** (rewardAmount)
   - 默认值：50元
   - 说明：每成功推荐一位用户，推荐人和被推荐人各获得的奖励金额

2. **推荐码最大使用次数** (maxUses)
   - 默认值：10次
   - 说明：每个推荐码最多可以被使用的次数

3. **推荐码有效期**（可选）
   - 说明：推荐码的有效时间，超过时间后失效

## 数据同步

推荐码奖励记录会自动同步到两个地方：

1. **个人信息 > 推荐奖励 > 推荐记录**
   - 显示推荐相关的详细记录
   - 包含推荐类型标签（推荐成功/使用推荐码）
   - 仅显示推荐相关的交易

2. **使用记录 > 账户明细**
   - 显示所有账户交易记录
   - 推荐奖励显示为"赠送 - 推荐奖励"
   - 与充值、消费等其他交易一起展示
   - 便于用户查看完整的资金流水

当用户获得推荐奖励时，系统会自动在两个位置添加相应记录，确保数据的一致性和完整性。
