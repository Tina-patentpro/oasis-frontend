## 💡 交互设计说明

### 菜单触发方式

- **2级菜单**: Tab切换、下拉展开
- **3级菜单**: 点击、悬停、右键
- **4级菜单**: 点击后弹出对话框或侧边面板

### 菜单样式规范

- 使用圆角设计 (rounded-lg, rounded-xl)
- 悬停效果 (hover:bg-gray-50)
- 主题色适配 (theme-aware)
- 图标 + 文字组合
- 合理的间距和对齐

### 响应式考虑

- 移动端：简化菜单层级
- 平板：保持完整功能
- 桌面：显示所有选项
