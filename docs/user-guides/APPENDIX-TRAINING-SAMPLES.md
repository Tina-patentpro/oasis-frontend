## 快速速查表

### 培训顺序速查

1. 登录页
2. 四块区域总览
3. 左侧选工具和模型
4. 中间输入并生成
5. 结果区复制、下载、下一步
6. 右侧对话补充
7. 关联项目
8. 讲会话和项目管理
9. 讲余额、流水、帮助、客服
10. 回答常见问题

### 售后判断速查

| 问题现象       | 先看哪里                                     |
| -------------- | -------------------------------------------- |
| 登不进去       | 手机号、验证码、登录方式、密码入口           |
| 按钮灰了       | 输入内容、会话状态、余额、是否正在生成       |
| 看不到工具     | 后台配置、模型喜好设定、页面刷新             |
| 看不到历史资料 | 项目关联、筛选条件、是否真的有历史数据       |
| 任务像没动     | 异步任务中心、通知中心                       |
| 下载不了       | 是否已有内容、是否已有文件、下载弹窗是否有项 |
| 页面显示怪     | 强制重新加载                                 |
| 客户怕丢数据   | 先导出，再删除                               |

### 讲解时最值得强调的 6 句话

1. 平台是工作台，不是单个聊天框。
2. 左边选工具，中间走主流程，右边做补充协作。
3. 会话可以先独立存在，后面再挂项目。
4. 工具和模型会按后台配置变化，以页面实际显示为准。
5. 删除前先导出，这是最稳妥的习惯。
6. 遇到异常先看任务、通知和强制重新加载。
