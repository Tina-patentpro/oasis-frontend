# 网页性能监控使用说明

## 功能概述

我已经为您的网站实现了完整的网页性能监控功能，能够检测和记录网页打开时间及其他关键性能指标。

## 实现的功能

### 1. 性能监控模块 (`src/monitoring/performance-monitor.ts`)

- **页面加载时间**: 从开始导航到页面完全加载的时间
- **DOM 解析时间**: DOM 结构解析所需的时间
- **资源加载时间**: 静态资源（CSS、JS、图片等）加载时间
- **首字节时间 (TTFB)**: 服务器响应时间
- **Web Vitals 指标**:
  - 首次内容绘制 (FCP)
  - 最大内容绘制 (LCP)
  - 首次输入延迟 (FID)
  - 累积布局偏移 (CLS)

### 2. 可视化展示组件 (`src/components/monitoring/PerformanceMetrics.tsx`)

- 右下角浮动按钮，点击显示详细性能指标
- 实时性能等级评估（优秀/良好/一般/较差）
- 智能优化建议
- 数据复制和刷新功能

### 3. 自动集成

- 在应用启动时自动初始化
- 在开发环境下自动输出性能指标到控制台
- 与现有监控系统（Sentry）无缝集成

## 使用方法

### 查看性能指标

1. 打开网站 http://localhost:5174/
2. 等待页面完全加载
3. 点击右下角的 "📊 性能" 按钮
4. 查看详细的性能指标报告

### 性能等级说明

- **优秀** (< 1秒): 页面加载速度很快
- **良好** (1-2秒): 页面加载速度正常
- **一般** (2-3秒): 页面加载速度较慢
- **较差** (> 3秒): 页面加载速度很慢，需要优化

### 优化建议

系统会根据性能数据自动提供优化建议：

- **页面加载时间过长**: 优化资源大小和数量
- **DOM 解析时间过长**: 优化 DOM 结构
- **服务器响应慢**: 优化服务器性能
- **内容绘制慢**: 优化关键资源加载
- **布局偏移大**: 为图片和广告设置固定尺寸

## 开发者信息

### API 接口

```typescript
// 获取性能监控实例
const monitor = getPerformanceMonitor()

// 获取当前性能指标
const metrics = monitor.getMetrics()

// 获取性能等级
const grade = monitor.getPerformanceGrade()

// 获取优化建议
const recommendations = monitor.getPerformanceRecommendations()
```

### 事件监听

```typescript
// 监听性能指标更新
window.addEventListener('performance-metrics', (event) => {
  const metrics = event.detail
  console.log('性能指标:', metrics)
})
```

## 环境变量配置

可以通过以下环境变量控制性能监控行为：

```bash
# 启用 Web Vitals（默认启用）
VITE_ENABLE_WEB_VITALS=true

# Sentry 配置
VITE_SENTRY_DSN=your-dsn-here
VITE_SENTRY_ENV=production
VITE_SENTRY_TRACES_SAMPLE_RATE=0.1

# 监控标签
VITE_MONITORING_TAGS={"version": "1.0.0", "environment": "prod"}
```

## 注意事项

1. **首次加载**: 性能监控需要在页面完全加载后才能收集到完整数据
2. **浏览器兼容性**: 需要 IE11+ 或现代浏览器支持
3. **性能影响**: 监控代码本身的开销极小（< 1ms）
4. **数据准确性**: 建议在真实网络环境下测试获得准确数据

## 故障排除

### 常见问题

**Q: 性能指标显示为 "--"**
A: 页面可能还在加载中，请等待完全加载后再查看

**Q: 某些指标没有数据**
A: 某些 Web Vitals 指标需要用户交互才会触发，如 FID

**Q: 性能监控按钮不显示**
A: 检查浏览器控制台是否有错误信息，确保组件正常加载

### 调试方法

1. 打开浏览器开发者工具
2. 查看 Console 标签页的性能监控输出
3. 检查 Network 标签页的资源加载时间
4. 使用 Performance 标签页进行详细分析
