❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 打开 index.html 显示空白？
A: 确保打开的是 dist 文件夹里的 index.html

Q: 需要安装什么软件吗？
A: 不需要！直接用浏览器打开即可

Q: 支持哪些浏览器？
A: Chrome、Firefox、Edge、Safari 都支持

Q: 可以修改网站吗？
A: 可以！修改 src 文件夹的代码后运行 npm run build
