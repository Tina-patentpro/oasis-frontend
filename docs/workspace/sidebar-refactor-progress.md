# 左侧栏改造进展记录

> 用于跟踪阶段性任务的完成情况，并同步关键风险与待办。

- `LeftSidebar.tsx`：完成结构梳理，确认主要分区（工具、模型、会话、项目）。

- 项目卡片信息收敛到项目名称、客户、会话统计，折叠逻辑按手动 / 搜索状态区分。
- 会话菜单统一入口，保持与右栏交互的一致性。

- 待确认：是否补充快速筛选（标签、最近打开）等扩展能力。
