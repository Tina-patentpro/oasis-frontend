# 左侧栏冒烟测试清单

> 目的：验证新的左栏布局在常见操作路径下的稳定性和可用性，整套执行约 10 分钟。

## 1. 基础准备

- 使用隐私窗口或清空本地缓存，确保初始状态干净。
- 以普通业务账号登录到工作区首页。

## 2. 独立会话

1. 新建一条未关联项目的会话并填入演示内容。
2. 打开“历史会话”并验证：
   - 空态提示文案正常，示例卡片展示 3 条示例。
   - 点击会话标题可以打开会话，左栏保持选中状态。

## 3. 项目列表

1. 切换到“项目管理”视图。
2. 关键检查：
   - 卡片仅显示项目名称、客户以及“关联会话数”按钮。
   - 不再出现项目编号、最近活动时间或“最近访问”模块。
   - 切换“待进行 / 已归档”状态按钮时列表正常刷新。
3. 新建或刷新任意项目以确认空态与搜索提示文案正确。

## 4. 项目操作

1. 双击项目标题进入编辑，回车保存后状态保持不变。
2. 双击客户名称进入编辑，输入新客户并失焦自动保存。
3. 展开卡片操作菜单：
   - 归档 / 取消归档按钮按项目当前状态显示正确。
   - 删除操作弹出确认提示，并在取消后保持原状态。

## 5. 会话交互

1. 展开项目卡片，点击任意会话名称，右栏同步切换。
2. 打开会话更多菜单，验证保留的“重命名 / 关联项目 / 导出 / 删除”动作有效。
3. 会话重命名后，输入框自动聚焦并支持回车确认、Esc 取消。

## 6. 搜索与折叠

1. 在搜索框输入关键字，仅保留匹配的项目和会话；项目折叠开关被禁用。
2. 清除搜索词后，手动折叠 / 展开项目，刷新页面后仍保留手动状态。

## 7. 异常提示

- 触发网络失败（可暂时断网）并刷新，会话与项目区域分别展示错误提示，而不会出现空白。
- 只要存在项目或会话，空态信息块不会出现。
