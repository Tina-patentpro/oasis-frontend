### 🔹 1. GET /cms/model-categories - 工作流分类标签

#### ✅ 确认说明

本API由CMS管理后台提供，返回工作流的分类数据，用于渲染左侧边栏的分类标签页，实现工作流的分组展示功能。

#### API与UI对应关系

**UI组件位置：** `WorkspaceLeftSidebar` > `CategoryTabs`

**API响应驱动UI渲染逻辑：**

- API返回的分类列表直接映射为标签页组件
- 每个分类对象渲染为一个可点击的标签
- 当前选中的分类通过`activeCategory`状态高亮显示
- 用户点击分类标签后，触发`GET /cms/tools?category={categoryId}`获取该分类下的工作流

#### 字段映射表格

| API响应字段          | 类型    | UI显示位置        | 组件属性/样式                  | 说明                   |
| -------------------- | ------- | ----------------- | ------------------------------ | ---------------------- |
| `data.categories[]`  | array   | 左侧边栏顶部      | CategoryTabs容器               | 分类列表容器           |
| `categories[].id`    | string  | 标签的data-id属性 | `data-category-id`             | 用于点击事件的分类标识 |
| `categories[].name`  | string  | 标签文本          | `<Tab>{name}</Tab>`            | 分类名称显示           |
| `categories[].icon`  | string  | 标签图标          | `<Icon src={icon} />`          | 分类图标URL            |
| `categories[].count` | integer | 标签右上角徽章    | `<Badge>{count}</Badge>`       | 该分类下工作流数量     |
| `categories[].color` | string  | 标签颜色主题      | `className={color}`            | Tailwind颜色类名       |
| `categories[].order` | integer | 标签排序          | `sort((a,b)=>a.order-b.order)` | 显示顺序控制           |

│ - 遍历 categories[] 数组     │
│ - 每个分类渲染为Tab组件      │

#### 设计文档依据

> **引用自《网站设计目标说明.md》§2.1：**
>
> "左边栏中工作流分类和选择的内容，由管理后台进行预设。用户选择后，前端自动在中栏向管理后台调用对应的 API"

> **功能对照表（功能编号3a）：**
>
> | 功能编号 | 功能说明         | 相关接口                                        |
> | -------- | ---------------- | ----------------------------------------------- |
> | 3a       | 工作流分类与选择 | `GET /cms/model-categories`<br>`GET /cms/tools` |

#### 总结要点

1. **单一数据源：** 分类数据完全由CMS后台提供，前端不做硬编码
2. **动态渲染：** 支持管理员在后台动态添加/删除/排序分类
3. **级联加载：** 分类选择触发工作流列表的联动更新
4. **视觉反馈：** 提供图标、颜色、计数等多维度视觉信息
5. **性能优化：** 分类数据可缓存，减少重复请求

### 🔹 2. GET /cms/tools - 工作流项目卡片

#### ✅ 确认说明

本API返回可用的工作流工具列表，用于在中间栏渲染工作流卡片。每个卡片展示工作流的基本信息，用户点击后进入详情页或直接启动工作流。

#### API与UI对应关系

**UI组件位置：** `WorkspaceCenterPanel` > `WorkflowGrid` > `WorkflowCard`

**API响应驱动UI渲染逻辑：**

- API返回的工具列表渲染为卡片网格布局
- 每个工具对象对应一个WorkflowCard组件
- 支持按分类筛选（category参数）
- 支持关键词搜索（keyword参数）
- 卡片点击后跳转到工作流详情页或执行页

#### 字段映射表格

| API响应字段             | 类型    | UI显示位置       | 组件属性/样式                               | 说明                 |
| ----------------------- | ------- | ---------------- | ------------------------------------------- | -------------------- |
| `data.tools[]`          | array   | 中间栏网格容器   | `<Grid>`                                    | 工作流卡片列表       |
| `tools[].id`            | string  | 卡片data-id      | `data-tool-id={id}`                         | 工作流唯一标识       |
| `tools[].name`          | string  | 卡片标题         | `<h3>{name}</h3>`                           | 工作流名称           |
| `tools[].description`   | string  | 卡片描述文本     | `<p>{description}</p>`                      | 工作流简介           |
| `tools[].icon`          | string  | 卡片顶部图标     | `<img src={icon} />`                        | 工作流图标           |
| `tools[].category`      | string  | 卡片分类标签     | `<Badge>{category}</Badge>`                 | 所属分类             |
| `tools[].tags[]`        | array   | 卡片标签组       | `{tags.map(t=><Tag>{t}</Tag>)}`             | 功能标签             |
| `tools[].status`        | string  | 卡片状态指示器   | `<StatusBadge status={status} />`           | 可用/维护中/即将上线 |
| `tools[].popularity`    | integer | 卡片右上角徽章   | `<Badge>🔥{popularity}</Badge>`             | 使用热度             |
| `tools[].executionCost` | object  | 卡片底部成本信息 | `<CostInfo>{credits}点数</CostInfo>`        | 执行成本预估         |
| `tools[].thumbnailUrl`  | string  | 卡片预览图       | `<img src={thumbnailUrl} />`                | 缩略图（可选）       |
| `tools[].quickStart`    | boolean | 快速启动按钮     | `{quickStart && <Button>一键执行</Button>}` | 是否支持快速启动     |

### 🔹 3. GET /api/workflows - 工作流列表

#### ✅ 确认说明

本API提供工作流的分页查询功能，支持按分类、关键字筛选。与`GET /cms/tools`不同，本API返回的是用户可执行的工作流实例列表，包含更详细的执行信息。

#### API与UI对应关系

**UI组件位置：** `WorkflowCenterPage` > `WorkflowList` > `WorkflowListItem`

**API响应驱动UI渲染逻辑：**

- API返回的工作流列表渲染为列表视图或网格视图
- 每个工作流对象对应一个列表项或卡片
- 支持分页加载（pagination对象）
- 支持筛选和排序
- 点击工作流进入详情页或执行页

#### 字段映射表格

| API响应字段             | 类型    | UI显示位置     | 组件属性/样式                                    | 说明                      |
| ----------------------- | ------- | -------------- | ------------------------------------------------ | ------------------------- |
| `data.items[]`          | array   | 工作流列表容器 | `<WorkflowList>`                                 | 工作流列表                |
| `items[].id`            | string  | 列表项data-id  | `data-workflow-id={id}`                          | 工作流ID                  |
| `items[].name`          | string  | 列表项标题     | `<h4>{name}</h4>`                                | 工作流名称                |
| `items[].category`      | string  | 分类标签       | `<CategoryBadge>{category}</CategoryBadge>`      | 所属分类                  |
| `items[].description`   | string  | 描述文本       | `<p className="text-gray-600">{description}</p>` | 简要描述                  |
| `items[].icon`          | string  | 列表项图标     | `<img src={icon} className="w-12 h-12" />`       | 工作流图标                |
| `items[].tags[]`        | array   | 标签组         | `{tags.map(tag=><Tag key={tag}>{tag}</Tag>)}`    | 功能标签                  |
| `items[].version`       | string  | 版本号显示     | `<span className="text-xs">v{version}</span>`    | 当前版本                  |
| `items[].lastUpdatedAt` | string  | 更新时间       | `<TimeAgo date={lastUpdatedAt} />`               | 最后更新时间              |
| `items[].status`        | string  | 状态指示器     | `<StatusBadge status={status} />`                | published/draft/archived  |
| `items[].visibility`    | string  | 可见性标识     | `<VisibilityIcon type={visibility} />`           | team/organization/private |
| `data.pagination`       | object  | 分页控件       | `<Pagination {...pagination} />`                 | 分页信息                  |
| `pagination.page`       | integer | 当前页码       | `currentPage={page}`                             | 当前页                    |
| `pagination.pageSize`   | integer | 每页条数       | `pageSize={pageSize}`                            | 每页记录数                |
| `pagination.total`      | integer | 总数显示       | `共{total}个工作流`                              | 总记录数                  |
| `pagination.hasMore`    | boolean | 加载更多按钮   | `{hasMore && <Button>加载更多</Button>}`         | 是否有更多数据            |

### 🔹 14. POST /api/files/upload - 文件上传

#### ✅ 确认说明

本API是文件上传的核心接口，支持在工作流执行、对话流交互时上传文件附件。前端需先调用此API上传文件，获取fileId后再将fileId传递给工作流执行或对话接口。

#### API与UI对应关系

**UI组件位置：** `FileUploadButton` > `FileUploadProgress` > `FileList`

**API响应驱动UI渲染逻辑：**

- 用户点击文件上传按钮选择文件
- 前端调用本API逐个上传文件
- 实时显示上传进度条
- 上传成功后在文件列表显示文件卡片
- 获取的fileId用于后续的工作流执行或对话请求

#### 字段映射表格

| API请求/响应字段       | 类型    | UI显示位置   | 组件属性/样式                    | 说明                                         |
| ---------------------- | ------- | ------------ | -------------------------------- | -------------------------------------------- |
| **请求体 - file**      | File    | 文件选择器   | `<input type="file" />`          | 要上传的文件对象                             |
| **请求体 - purpose**   | string  | 隐藏字段     | 上传用途标识                     | workflow-input/chat-attachment/project-asset |
| **请求体 - projectId** | string  | 项目关联     | 可选                             | 关联的项目ID（可选）                         |
| **响应 - fileId**      | string  | 文件引用ID   | 存储到state                      | 上传后的文件唯一标识                         |
| **响应 - fileName**    | string  | 文件名显示   | `<span>{fileName}</span>`        | 原始文件名                                   |
| **响应 - fileSize**    | integer | 文件大小显示 | `{formatFileSize(fileSize)}`     | 文件大小（字节）                             |
| **响应 - mimeType**    | string  | 文件类型图标 | `<FileIcon type={mimeType} />`   | 文件MIME类型                                 |
| **响应 - uploadedAt**  | string  | 上传时间     | `上传时间：{uploadedAt}`         | 上传时间戳                                   |
| **响应 - expiresAt**   | string  | 过期提示     | `有效期至：{expiresAt}`          | 文件过期时间                                 |
| **响应 - downloadUrl** | string  | 下载链接     | `<a href={downloadUrl}>下载</a>` | 临时下载URL（可选）                          |
