用户注册

支持邀请码或邮箱验证方式注册新用户，包含防刷和节流机制。

Authorizations:
BearerAuth
Request Body schema: application/json
required
email
required
string <email>

用户邮箱。

password
required
string >= 8 characters

密码，至少8位。

displayName
required
string [ 2 .. 50 ] characters

显示名称。

invitationCode
string

可选，邀请码。

acceptTerms
required
boolean

是否同意服务条款。

locale
string
Default: "zh-CN"

语言偏好。

Responses

生产环境

https://api.example.com/api/auth/register

沙箱环境

https://sandbox.example.com/api/auth/register

}
