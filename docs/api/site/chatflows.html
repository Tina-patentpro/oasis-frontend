BearerAuth
Request Body schema: application/json
required
name
required
string

对话流名称。

description
string

简要描述。

cloneFrom
string

可选，基于既有 chatflow 复制。

visibility
string
Default: "private"
Enum: "private" "team" "global"

初始可见范围。

required
object (ChatPromptConfig)

提示词配置。

Array of objects (ChatflowInputChannel)

输入渠道列表。

instructionIds
Array of strings

关联的指令 ID 列表。
