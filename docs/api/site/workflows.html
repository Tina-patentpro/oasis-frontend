Workflows

工作流管理与执行接口

分页查询工作流目录

按分类、关键字等条件分页检索当前租户可用的工作流，用于工作流中心列表页加载与搜索联想。

BearerAuth
query Parameters

string

工作流分类，由 CMS 配置。

keyword
string

名称、描述模糊搜索。

page
integer >= 1
Default: 1
pageSize
integer [ 1 .. 200 ]
Default: 20

触发工作流执行

根据提交的动态输入与附件立即启动工作流，返回执行 ID 供前端轮询结果与展示实时进度，适用于"立即运行""一键生成"等高频业务场景。

Authorizations:
BearerAuth
path Parameters
workflowId
required
string
Request Body schema: application/json
required
required
object

动态参数，符合 inputSchema。

Array of objects

附件上传配置列表。

projectId
string

可选，关联项目。

presetId
string

可选，链式调用预设。

metadata
object

扩展字段（例如来源页面、触发方式）。

Responses

生产环境

https://api.example.com/api/workflows/{workflowId}/execute

沙箱环境

https://sandbox.example.com/api/workflows/{workflowId}/execute

获取工作流历史执行记录

按时间倒序返回执行历史，包含输入摘要，可用于"快速重复执行"。

Authorizations:
BearerAuth
path Parameters
workflowId
required
string
query Parameters
page
integer >= 1
Default: 1
pageSize
integer [ 1 .. 100 ]
Default: 20
projectId
string

过滤指定项目的执行记录。

status
string
Enum: "queued" "running" "completed" "failed" "cancelled"
from
string <date-time>

起始时间（ISO8601）。

to
string <date-time>

结束时间（ISO8601）。

includeInputsSummary
boolean
Default: true

是否包含输入摘要
