# 权限与角色矩阵

| 角色    | 描述             | 能力摘要                                  |
| ------- | ---------------- | ----------------------------------------- |
| admin   | 平台管理员       | 管理工作流/对话流配置、用户权限、账务审核 |
| manager | 团队负责人       | 管理项目、查看团队统计、审批导出          |
| user    | 普通用户         | 执行工作流、发起对话、管理自己的项目/会话 |
| auditor | 审计角色（可选） | 只读访问日志与统计信息                    |
