# 通用错误码约定

| 错误码       | HTTP 状态 | 描述           | 说明                      |
| ------------ | --------- | -------------- | ------------------------- |
| AUTH-401-01  | 401       | 未提供有效凭证 | Bearer Token 缺失或已过期 |
| AUTH-403-01  | 403       | 权限不足       | 当前用户无权访问该资源    |
| DATA-404-01  | 404       | 资源不存在     | id 不存在或已删除         |
| VALID-400-01 | 400       | 请求参数错误   | 未通过 schema 校验        |
| WF-409-01    | 409       | 工作流状态冲突 | 工作流执行中禁止重复提交  |
| CHAT-409-01  | 409       | 对话状态冲突   | 对话流当前不接受新消息    |
| SERV-500-01  | 500       | 服务器内部错误 | 后端未捕获异常            |
| THIRD-502-01 | 502       | 第三方服务异常 | 例如 Dify/支付网关超时    |
